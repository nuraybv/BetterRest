
# BetterRest 🌙

BetterRest is a simple iOS application built with SwiftUI that predicts an ideal bedtime based on the user's wake-up time, desired sleep duration, and daily coffee intake.

## Features

- ⏰ Select your desired wake-up time.
- 😴 Set your desired amount of sleep.
- ☕ Choose your daily coffee intake.
- 🌙 Get a recommended bedtime automatically.
- 🔄 Update the result whenever your preferences change.

## Technologies Used

- Swift
- SwiftUI
- Core ML
- Xcode

## What I Learned

While building this project, I practiced:

- Building user interfaces with SwiftUI.
- Managing state using `@State`.
- Working with `DatePicker`, `Stepper`, and `Picker`.
- Responding to changes with `onChange`.
- Integrating a machine learning model into an iOS application.
- Working with dates and time calculations.

## How It Works

The app uses a Core ML model to estimate the amount of sleep a user needs based on the selected inputs. It then calculates and displays a recommended bedtime.
